# Shared contracts

The three Draft-07 JSON Schemas in `schemas/` are the canonical exchange format.
`src/generated/` is committed for editor support and regenerated by
`npm run contracts:generate`; `npm run contracts:check` catches drift.

- `Lesson`: case/media, checkpoints, questions, independent reviewed feedback.
- `FrameResult`: one source's geometry for exactly one original image frame.
- `LearnerAttempt`: one committed choice, elapsed time, cumulative hint exposure.

Consume `parseLesson`, `parseFrameResult`, and `parseLearnerAttempt` from
`@holospex/contracts` at browser input/storage boundaries. Python reads the same
frame schema and implements matching geometry/provenance consistency checks.
JSON Schema alone cannot express polygon bounds relative to width/height or
cross-record links; the boundary parsers and integration checks enforce these.

`anatomy.json` owns internal IDs, display labels, and colors. Dataset integer
labels must be explicitly mapped to these IDs; never assume numbering matches.
The polygon format initially supports one simple contour per instance. Do not
discard holes silently; add a reviewed approximation or evolve the format.

Coordinates are continuous edges in the original image: `(0, 0)` at top left,
x right, y down, inclusive bounds through `(width, height)`. Millisecond
timestamps are relative to media start. Frame numbers describe that original
media, not the index of a sampled array.

`ok` with no structures means successful processing with no exported detections.
`unsupported`, `missing`, and `error` require empty geometry and a reason. These
technical states cannot author the learner's `cannot_determine` answer.
Predictions require model identity and structure confidence; reviewed geometry
does not get invented confidence scores. Propagation must reference an earlier
timestamp and be marked explicitly.

For a contract change, edit schema → regenerate types → update fixtures and
both consumers → run checks. Keep this sequence in one handoff and tell the
affected teammate which field/behavior changed. Schema validation does not
certify medical review, correctness, or permission to use an asset.
